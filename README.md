# 📝 QuickNotes - Interactive Note-Taking Web App

A clean, responsive, and intuitive note-taking web application that allows users to effortlessly create, view, organize, and delete notes with instant local storage persistence.

---

## ✨ Key Features
- **CRUD Functionality:** Easily create, read, update, and delete notes in real time.
- **Data Persistence:** Uses browser `localStorage` so notes remain saved even after refreshing or closing the browser.
- **Instant Search:** Quickly filter and find notes by keywords.
- **Clean & Modern UI:** Designed with a user-friendly, distraction-free interface.
- **Mobile Friendly:** Fully responsive design that works on mobile phones, tablets, and desktops.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic document structure
- **CSS3:** Modern UI styling, Grid/Flexbox layouts & smooth transitions
- **JavaScript (Vanilla ES6+):** DOM manipulation, event handling & `localStorage` API

---

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/mkalsariya9127/note-project-js.git
   ```
2. Open `index.html` in your favorite browser.
3. Start creating and organizing your notes!
